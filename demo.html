Solution blueprint · Reuse / Extend / New

Haravan Resource Mapping

Ranh giới dữ liệu để tránh xây lại những gì Commerce Core đã hỗ trợ.

REUSEProduct / Variant / SKU

Mã dịch vụ, giá, danh mục, trạng thái bán. Inventory giữ nguyên cho vật tư/hàng hóa.

EXTENDService metadata

Duration, eligible staff, non-stock service, liên kết SKU với booking.

BUILD NEWBooking / Session

Khung giờ, KTV, trạng thái, chống trùng lịch, check-in và hoàn tất.

REUSE + EXTENDCustomer / Order / POS

Liên kết khách và order với booking. Payment được minh họa, chưa tích hợp giao dịch thật.

BUILD NEW · P2Package entitlement

Ledger số buổi, hạn dùng, khấu trừ và hoàn tác.

BUILD NEW · P2Commission ledger

Quy tắc, người hưởng, điều kiện ghi nhận, đối soát hoa hồng.

BUILD NEW · P3Prepaid / Recurring

Sổ số dư thẻ trả trước và chuỗi lịch định kỳ.

BUILD NEW · P4Resources / Self-booking

Phòng/giường, công suất, trang khách tự đặt và thông báo.
